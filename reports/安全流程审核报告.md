## 四、GitHub CI 门禁矩阵（本次落地）

| 工作流 | 触发 | 内容 | 预算 | 产物 |
|---|---|---|---|---|
| `ci.yml` → `quality` | push main/develop、PR | install → build → test(500) → scan（ruff/bandit/pip-audit/密钥/覆盖率） | ≤15min | `reports/ci/`、`dist/` |
| `ci.yml` → `test-windows` | 同上 | Windows 交叉回归（test 500） | ≤20min | 测试报告 |
| `ci.yml` → `dependency-review` | PR | 依赖审查（high 阻断） | ≤10min | 审查结论 |
| `codeql.yml` → `analyze` | push/PR/每周一 | CodeQL security-extended | ≤20min | SARIF→Security 面板 |
| `release.yml` → `verify` → `publish` | tag `v*` | 全量测试(10000)+扫描+构建；发布校验、PyPI OIDC（可选）、GitHub Release、构建溯源 | ≤45min | Release 资产 + 校验和 |
| `nightly.yml` → `nightly-full` | 每日 02:30 CST / 手动 | Fuzz 10000 + 全量扫描 + **全历史密钥扫描** | ≤30min | 报告归档 30 天 |
| `live-smoke.yml` → `live-smoke` | 仅手动 | 真实凭据 token→网关→READY（environment 隔离） | ≤10min | 无制品 |

所有工作流：顶层 `permissions: contents: read`、`concurrency` 去重、`timeout-minutes`、`persist-credentials: false`；不使用 `pull_request_target`。
